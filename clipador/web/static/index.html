        Provedores de IA

        Assinatura ≠ API. Pagar o ChatGPT Plus, o Claude Pro ou o Gemini Advanced não dá acesso à API. A API é cobrada à parte, por uso: crie uma chave no painel do provedor. A chave fica no Gerenciador de Credenciais do Windows e nunca aparece de novo na tela. Só texto do projeto é enviado (roteiro, legenda, rótulos); vídeo e áudio nunca saem do seu PC. Sem IA, tudo continua funcionando à mão.

        Limites

        O orçamento só soma custos conhecidos (tabela oficial da Anthropic). OpenAI e Gemini: acompanhe no painel deles.

        Como usar a timeline

        Arraste um trecho para mudar a ordem · puxe as bordas para aparar · clique para pôr o cursor · S divide · D duplica · Delete remove · ← → movem o cursor (Shift = 1 s) · Ctrl+Z desfaz. Também dá para reordenar com ↑ ↓ na lista ao lado. Arraste arquivos de vídeo para a janela para importar.

        ⚖️ Editor A × B — corte os dois vídeos com o mesmo tempo

        1. No vídeo de cima (A), ache a cena e marque Início A e Fim A.
        2. No vídeo de baixo (B), ache a mesma cena e marque Início B. O fim do B é calculado (mesmo tempo do A). Se preferir, marque Fim B: o fim do A acompanha.
        3. Confira com ▶ Tocar os dois e clique em + Adicionar à montagem. Clique num trecho da lista para editá-lo aqui.
